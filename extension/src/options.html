    Privacy

    The page list lives entirely in the part of the URL after #, which browsers never send to a server. tabs reads the current window's URLs and titles only when you press a button; tabGroups reads and names tab groups. One content script runs on the viewer page only (the packaged host, plus a viewer address you set above after approving that one host). Password links are encrypted in your browser — the password is never stored or sent. Site icons and the shortener are the only features that can make a network request, both off-able above.
