    Privacy

    Tab Share never sends your tabs or links anywhere. The whole collection is packed into the part of the URL after #, which browsers do not transmit to servers. The tabs permission is used only to read the current window's URLs and titles when you press the button. The optional tabGroups permission, if you enable it, is used only to read and name tab groups.

    One content script runs on the viewer page only — the default host and localhost, plus a custom viewer URL you save above (it asks for that host once). It reads the link's # fragment to offer the "open with the extension" banner. Nothing it does leaves your device.
